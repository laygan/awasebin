## 未実装・制限

- TURNの提供・接続量・費用上限監視。TURNへ自動接続しないため料金は発生させません。
- ICE候補・経路種別の収集と可視化、接続成功率ダッシュボード。
- バックアップとヘルス監視の実運用。スクリプト・systemdタイマーは同梱し、配備先でage公開鍵・保存先・通知先・復元試験の設定が必要です。
- P2P中の転送取消UI、IndexedDBの利用済みピース清掃UI。受信完了・中断後にもブラウザ領域へデータが残ります。運用前に保持・清掃方式を確定してください。
- 24時間を超えたアップロードの権限延長。現時点では失効後は新しいセットへの再送が必要です。
- 40MP超や未対応画像形式はプレビューなし。元ファイルは取得可能です。
- メタデータバックアップ内の削除ポリシーは運営者による確定が必要です。

## 出荷判定

現在は出荷不可です。依存導入後に `npm test` / `npm run build` を成功させ、上表の実試験と未実装の必須要件を解消してください。特にNodeシードとブラウザの実接続、100GB保存、CGNAT、IPv4専用経路を確認するまでは `P2P_ENABLED=true` に変更せず、「100GB P2P完全対応」と表示しないでください。
